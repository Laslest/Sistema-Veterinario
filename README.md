# Sistema Veterinário

Sistema de agendamento de atendimentos veterinários desenvolvido como projeto da disciplina de Projeto de Software.

O sistema terá o médico veterinário como elemento central, permitindo o gerenciamento de atendimentos realizados em clínicas veterinárias ou a domicílio.

Os clientes poderão cadastrar seus animais e realizar agendamentos, enquanto os médicos veterinários poderão consultar sua agenda com data, horário e local dos atendimentos.
